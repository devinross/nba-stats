Twemoji SVGs for the team badges on the social cards (scripts/og-cards.mjs),
one per team emoji, named by codepoint. From jdecked/twemoji v15.1.0

A team whose emoji has no file here gets its abbreviation on the card instead;
add the file from
https://cdn.jsdelivr.net/gh/jdecked/twemoji@15.1.0/assets/svg/<codepoint>.svg
